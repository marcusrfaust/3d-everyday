Decisões de Arquitetura

  • 3d-lib intocado: watcher + PG + D1 continuam; 3DE lê o D1 via REST server-only (mesmo padrão web/src/lib/d1.ts).
  • Astro 5 SSR + Tailwind v4, sem React na fase 1; islands só se justificadas.
  • Sem Stripe/Loops/Maps do storefront; checkout de reserva herdado do 3d-lib quando chegar a hora.
  • Taxonomia Jev (23 mapeamentos tag→categoria) vira navegação por facetas (categoria/tag/formato).
  • Medusa só na fase 3, plugado no 3DE — nunca no 3d-lib.
  • Moeda sem preferência hardcoded: padrão = 1ª região do backend; ?currency= vence cookie medusa_region; sem preço na moeda → fallback com aviso (nunca number inventado).
  • CSRF: Astro 5.18 sem allowlist nativa → src/middleware.ts próprio (allowlist 3de.focol.ai + localhost; PREVIEW_HOSTS exatos via env).
  • Cookies medusa_cart (httpOnly, 7d) + medusa_region (httpOnly, 1a), SameSite=Lax, Secure em PROD/https. IDs opacos validados (safeId), redirects internos (safeNext).
  • Pendências de produto (planos/créditos): quantos planos, expira ou acumula, re-download gasta de novo — aguardando Marcus.
